# 📊 상품별 묶음 & 옵션 판매 비중 분석기

카페24의 복잡한 텍스트형 옵션 데이터를 정제하여, 인기 옵션 조합과 판매 점유율을
자동으로 분석해주는 도구입니다.

---

## 🎯 주요 기능

* 카페24의 복잡한 **텍스트형 옵션 데이터**를 정제합니다.
* **인기 옵션 조합 TOP 20**을 자동으로 집계합니다.
* **단품 옵션별 판매 점유율(%)**을 차트로 제공합니다.

## 💻 사용 방법

1. 옵션 정보가 포함된 **주문 엑셀 파일**을 업로드합니다.
2. 자동으로 옵션 데이터가 정제되고 분석됩니다.
3. 인기 옵션 조합, 판매 점유율 차트를 확인합니다.
4. 필요 시 결과를 다운로드합니다.

## 🛠️ 기술 스택

* **Language**: Python
* **Web Framework**: Streamlit
* **Data Processing**: Pandas, OpenPyXL

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```
